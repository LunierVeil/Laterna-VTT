# CLAUDE.md

Открытый self-hosted VTT. Ранний прототип. Перед работой прочитай
`ARCHITECTURE.md` - там решения и их причины, а не описание кода.

## Запуск

```
cd server && uvicorn app.main:app --reload --port 8000   # SQLite, без настройки
cd web && npm run dev                                     # http://localhost:5173
```

Проверка бэкенда при живом сервере: `cd server && python smoke_test.py`.

## Правила, которые нельзя нарушать

1. **Сервер - источник правды.** Клиент шлёт команду, сервер валидирует,
   применяет и рассылает событие. Клиент не меняет состояние сам.
2. **Состояние сцены меняется только в `server/app/handlers.py`.**
   Новая возможность = новая команда там, а не правка моделей из
   случайного места.
3. **Броски кубов только на сервере**, через `secrets`. Клиент никогда
   не генерирует случайное число для броска.
4. **Валидация движения на сервере.** Это осознанное исключение из
   правила "геометрия на клиенте": иначе игрок шлёт `token.move`
   сквозь стену и сервер соглашается.
5. **Токены и стены не живут в React-стейте.** Они в PixiJS-сцене
   (`web/src/scene/stage.ts`). В `web/src/state/store.ts` только
   состояние интерфейса. Гонять перетаскивание через React - это
   ререндер на каждый кадр.
6. **Координаты хранятся в пикселях сцены, не в клетках.** Сетка - это
   отображение и привязка. Иначе гексы и бессеточные карты не вставить.
7. **Стены уже имеют все флаги** (`blocks_sight`, `blocks_sound`,
   `kind`, `door_state`), хотя работает пока только `blocks_movement`.
   Не удалять их "за ненадобностью" - они ждут этапа освещения.
8. **Отменять можно только своё.** Ctrl+Z убирает стены, созданные этим
   клиентом (отслеживаются по `cmd_id`). Удаление чужого - отдельная
   механика с правами, не горячая клавиша.

## Проверка фронтенда

Тайпчек и сборка НЕ доказывают, что приложение работает. Этот проект
уже ловил четыре бага, которые прошли `tsc` и `vite build`:
падение при двойном монтировании эффектов в StrictMode, потерю
снапшота, гонку двух стейджей и неработающий хит-тест по Graphics.

После изменений во фронтенде открывай приложение и смотри консоль
браузера, а не только вывод компилятора.

## Что осознанно не сделано

Динамическое освещение и полигоны видимости, туман войны, листы
персонажей, аутентификация. Порядок и причины - в
`ARCHITECTURE.md`, раздел "Что осознанно отложено".

**Аутентификации нет**: имя приходит query-параметром и не проверяется.
Помечено `TODO` в `server/app/main.py`. Не выставлять в интернет.

## Стиль общения

Отвечай по-русски, коротко и по делу, без лишней вежливости.
Дефисы вместо длинных тире.
