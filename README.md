# Lanterna

Открытый self-hosted VTT. Рабочее название, переименовать не проблема.

Состояние: ранний прототип. Работает сцена с сеткой, токены, стены,
чат и броски кубов. Динамического освещения пока нет - оно идёт после
того, как по карте станет можно просто играть.

## Что уже есть

- Сцена на PixiJS: панорама, зум, квадратная сетка
- Токены: создание, перетаскивание с привязкой к клетке, синхронизация между клиентами
- Стены: рисование цепочкой, блокировка движения **на сервере**
- Чат и броски кубов: `2d6+3`, `d20`, `4d6kh3`, `2d20kl1`
- Server-authoritative протокол: клиент шлёт команду, сервер рассылает событие

## Что осознанно не сделано

Динамическое освещение, туман войны, листы персонажей, аутентификация,
загрузка карт. См. ARCHITECTURE.md, раздел "Что осознанно отложено".

**Аутентификации нет.** Имя приходит query-параметром и никак не
проверяется. Не выставляйте это в интернет.

## Запуск

### docker

```
docker compose up --build
```

Фронт: http://localhost:5173, API: http://localhost:8000

### без docker

Бэкенд (SQLite, никакой настройки):

```
cd server
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Фронт:

```
cd web
npm install
npm run dev
```

### Проверка

```
cd server && python smoke_test.py
```

Проверяет порядок seq, подтверждение команд по cmd_id, блокировку
движения стеной и серверный бросок кубов.

## Управление

| | |
|---|---|
| Инструмент "Выбор" | ЛКМ тянет токен, по пустому месту - панорама |
| Инструмент "Токен" | клик ставит токен в клетку |
| Инструмент "Стена" | клик-клик рисует отрезок, дальше цепочкой; ПКМ - панорама |
| Колесо | зум к курсору |
| `/r 2d6+3` в чате | бросок |

## Структура

```
server/app/
  main.py        websocket, REST, применение команд под локом сцены
  handlers.py    единственное место, где меняется состояние
  models.py      SQLAlchemy, стены со всеми флагами с первого дня
  dice.py        парсер и бросок, только на сервере
  geometry.py    пересечение отрезков для валидации движения
  hub.py         комнаты, рассылка, лок на сцену
web/src/
  net/socket.ts  seq-дедупликация, оптимистичные изменения, переподключение
  scene/stage.ts вся PixiJS-сцена, React внутрь не лезет
  state/store.ts только состояние интерфейса
```

Перед тем как трогать код, прочитайте ARCHITECTURE.md - там решения,
а не описание.
