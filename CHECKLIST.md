# Ручная проверка

Как убедиться, что очередная итерация работает. Не заменяет просмотр
консоли браузера - он обязателен (см. CLAUDE.md).

## Запуск

```
./dev.sh          # сервер + фронт, Ctrl+C гасит оба
./dev.sh reset    # то же с чистой базой
./dev.sh check    # тайпчек + smoke_test, во втором терминале при живом сервере
```

Первый запуск сам создаст `server/.venv` и поставит `node_modules`.

## Два игрока на одной машине

Имя хранится в localStorage, а он у каждого адреса свой:

- игрок 1 - http://localhost:5173
- игрок 2 - http://127.0.0.1:5173

Окна поставь рядом: всё, что делает один, должно сразу появляться у
другого. Сменить имя: DevTools -> Application -> Local Storage ->
удалить `lanterna.user`, обновить страницу.

## Перед каждой проверкой

- [ ] F12 -> Console открыта, фильтр на Errors
- [ ] Обнови страницу (Ctrl+Shift+R) - ошибки при загрузке тоже ловим
- [ ] Индикатор в шапке зелёный, «на связи»

Красного в консоли быть не должно. Предупреждения React DevTools и
`[vite]` - норма.

## Базовое (проверять, что не сломалось)

- [ ] «Токен» -> клик ставит токен в центр клетки, второй игрок его видит
- [ ] «Выбор» -> токен тащится с привязкой к клетке, у второго тоже двигается
- [ ] Тащить токен сквозь стену -> тост «стена на пути», токен вернулся на место
- [ ] «Стена» -> клик-клик-клик рисует цепочку; Esc / ПКМ / клик в ту же точку заканчивают
- [ ] Ctrl+Z убирает свою последнюю стену; чужую - нет
- [ ] В чате `/r 2d6+3` -> бросок с кубами виден обоим
- [ ] Колесо - зум к курсору, тянуть по пустому месту - панорама

## Итерации

### 1. Удаление токена по Delete

- [ ] Игрок 1 ставит токен, «Выбор», кликает его (жёлтая обводка), Delete -> токен исчез у обоих
- [ ] Backspace делает то же самое
- [ ] Игрок 2 ставит токен, игрок 1 выбирает его и жмёт Delete -> тост «нельзя удалить чужой токен», токен на месте
- [ ] Курсор в поле чата, Delete/Backspace -> стирается текст, токен не трогается
- [ ] В режиме «Токен» или «Стена» Delete ничего не делает

### 2. Переименование и цвет

- [ ] Выбрал свой токен -> слева сверху панель с именем и цветами; клик по пустому месту -> панель пропала
- [ ] Новое имя + Enter -> подпись под токеном сменилась у обоих
- [ ] Набрал имя и кликнул по пустой сцене (без Enter) -> имя всё равно сохранилось
- [ ] Набрал, Esc -> вернулось старое имя, ничего не отправилось
- [ ] Стёр имя целиком, Enter -> вернулось старое (пустое имя нельзя)
- [ ] Клик по кружку палитры -> цвет сменился у обоих, выбранный кружок обведён
- [ ] Пунктирный кружок -> свой цвет; применяется, когда закрыл выбор цвета, а не на каждое движение
- [ ] Перетаскивание выбранного токена -> панель не мигает
- [ ] Игрок 2 выбирает токен игрока 1 -> «токен игрока ..., менять нельзя», полей нет
- [ ] Delete с курсором в поле имени стирает буквы, а не токен

### 3. Удаление стены в режиме «Стереть»

Перед проверкой `./dev.sh reset`: у стен новое поле, старая база не
запустится (сервер скажет об этом сам).

- [ ] Игрок 1 рисует пару стен, игрок 2 - свою
- [ ] Игрок 1, «Стереть», ведёт мышь над своей стеной -> красная подсветка, курсор-рука
- [ ] Над стеной игрока 2 -> блёклый серый ореол, курсор «нельзя»
- [ ] Клик по своей -> стена пропала у обоих, подсветка погасла сразу
- [ ] Клик по чужой -> тост «нельзя удалить чужую стену», стена на месте
- [ ] Тянуть по пустому месту -> панорама, ничего не удалилось
- [ ] Стена под токеном тоже подсвечивается и удаляется
- [ ] После удаления стены токен проходит там, где раньше упирался
- [ ] Ctrl+Z в режиме «Стена» по-прежнему убирает свою последнюю стену
