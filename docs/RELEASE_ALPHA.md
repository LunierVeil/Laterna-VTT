# Laterna VTT - альфа

Первая пробная версия: играем, чтобы найти, что ломается.

## Windows: скачать и запустить

1. Скачай `Laterna-VTT-...-windows.zip` ниже и распакуй в любую папку.
2. Дважды кликни `laterna.bat` и выбери в меню пункт **1. Игра через Porthole**.
   Python и всё остальное уже внутри архива, ставить ничего не нужно.
3. Дальше - по шагам на экране и в `docs/FIRST_SESSION.md`.

Linux и macOS: `git clone`, затем `./laterna.sh porthole` (нужны Python 3.11+ и Node.js).

## Чего в альфе нет

Динамического света и тумана (есть ручной туман у мастера), библиотек
(ассеты, бестиарий, заклинания), автоматики правил. Подробнее -
`docs/FIRST_SESSION.md`.

Проблемы - в [issues](https://github.com/LunierVeil/Laterna-VTT/issues).
