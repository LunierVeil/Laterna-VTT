# Beta — утверждённые решения и границы

Срез DOCS-00: master `ff9681769978e295a763bcdea8aba536b7967566`, 04.11.2026.
Это компактный реестр направлений владельца, а не свидетельство реализации.
[ROADMAP](ROADMAP.md) задаёт этапы, [ARCHITECTURE](ARCHITECTURE.md) разделяет AS-IS
и цель. Детальные интерфейсы утверждаются перед соответствующей реализацией.

## Статусы и приоритет

- **AS-IS** — подтверждено кодом на указанном SHA.
- **APPROVED** — утверждённое будущее требование; не равно «готово».
- **PROPOSED** — рабочий вариант реализации или backlog.
- **OPEN** — решение ещё нужно принять.
- **HISTORICAL** — сохранённое исследование/измерение на прежней базе.

Для факта реализации приоритет имеет код. Для будущего поведения — LTR-DEC/G;
часть III MASTER определяет зависимости, часть IV — рабочую декомпозицию.
Исследования и прежние концепции сами по себе не создают обязательств.

G2 не ограничивается журналом: он охватывает защищённые токены, геометрию,
сцены, данные ГМ, материалы и связанные приватные медиа. Проверка выполняется
на сервере при чтении, изменении и рассылке; UI и знание URL не предоставляют
прав. Точная policy/DDL для конкретных объектов остаётся предметом реализации.

## Архитектурные инварианты и порядок

**A → B → C → D → E**:

1. **A:** чистая геометрия LOS, базовый свет/FoW и серверная проверка секретности.
2. **B:** DataHome, проверяемый backup/restore, Alembic, безопасный Alpha upgrade;
   постепенное выделение ответственностей backend.
3. **C:** несколько сохранённых кампаний, одна активная партия, lifecycle и AccessPolicy.
4. **D:** остальные обязательные возможности Beta C, включая сохраняемую разведку,
   UVTT, ассеты, проверенный каталог и общие материалы/журнал/книгу/ширму.
5. **E:** стабилизация, Windows candidate, LAN/Porthole, полевые игры и release gate.

Если A требует новой таблицы или несовместимого persisted JSON, необходимая часть B
и проверенный upgrade предшествуют этому изменению. Нельзя обходить gate ручным
ALTER TABLE, удалением БД или бесконтрольным сочетанием create_all и Alembic.

Сервер определяет права и разрешённые recipients REST/WS/media/search. PixiJS
рисует, не решает доступ к секретам; клиентский campaign_id не доказательство прав.
Сохраняются seq/cmd_id/base_seq, FSD-09b, state/public и ограниченный state/bridge.
Координаты рендера и drag-preview остаются вне Zustand. Конкретный алгоритм LOS
и библиотека редактора этим реестром не выбираются.

Instance backup содержит согласованные БД всех кампаний, media и необходимые
ключи; restore проверяется. Экспорт одной кампании — отдельный переносимый продукт,
не восстановление экземпляра и не способ раздавать его ключи. Миграция Alpha —
копирование с проверкой, без уничтожения исходника.

## Не объявлять готовым

**AS-IS:** реализована Design System **Foundation/Components v0.3**, но не весь
интерфейс переведён на неё. Frontend FSD по FSD-09b завершён; один Zustand store
с public/bridge, системные bindings и renderer family на месте. FastAPI ещё не
переведён на целевой модульный монолит. SQLite используется сейчас, но устойчивый
DataHome, Alembic и стратегия G3 не внедрены. В Windows launcher есть ручная копия
остановленной Alpha; это не автоматический и не verified pre-upgrade backup.

LOS/динамический свет, сохраняемая разведка, новый AccessPolicy/изолированное
переключение кампаний, UVTT, Asset Library, встроенные 50 SRD существ и G6 материалы
ещё не реализованы. Ручной FoW и mob template/copy не являются этими функциями.
Подтверждённый CI из [CI_CD](CI_CD.md) не закрывает будущие acceptance gates,
юридическую проверку, restore или ручные B01/B02 через Porthole.
