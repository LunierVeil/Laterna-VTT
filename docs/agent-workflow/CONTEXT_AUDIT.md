A предписывал перед работой читать архитектуру, Beta-решения, roadmap и

Для воспроизведения извлеките байты через `git show SHA:путь`. Раздел начинается
со строки заголовка и заканчивается перед следующим заголовком того же или
более высокого уровня, включая вложенные подразделы. Суммируйте каждый
выбранный фрагмент один раз и отдельно считайте уникальные пути. Например,
межмодульный маршрут использует два фрагмента `ARCHITECTURE.md`, но один путь.

Выборочное чтение убирает 81–89% байтов относительно верхней оценки A.
Это измеренный объём выбранных фрагментов. Фактическое сокращение повторных
чтений и токенов на задачах Laterna остаётся **NOT VERIFIED**. Даже при меньшем
объёме выбранного текста файлов может быть больше.

Для description посчитано значение строки с LF. Для developer_instructions

материалов при запуске CLI не измерялись. Метаданные существующих Skills,
тела выбранных Skills, справки и контекст отдельного дочернего агента

транскрипта также увеличила бы объём. Такой режим не измерялся.

| P1 | [task-start](../../.agents/skills/task-start/SKILL.md), [handoff-resume](../../.agents/skills/handoff-resume/SKILL.md) и [pr-preflight](../../.agents/skills/pr-preflight/SKILL.md) требуют сверки Git. Сохранить действующий приоритет ограничений текущего задания. Проверить решения о Ready на двух PR с разными условиями. |

Многоступенчатый пример может восприниматься как обязательный даже для опечатки. | Дополнительное чтение и запуски без пользы для малой правки. | Передавать короткую сводку проверок, открывать только нужную процедуру и фиксировать пропуск неприменимого шага. Сравнить EVAL-02/03 с одним и несколькими Skills. |

Аудит не обнаружил активного противоречия в границах авторизации, данных и
merge между AGENTS, Skills и профилями. В ролях запрет записи уже привязан
к задаче чтения. Реальная песочница наследуется от родительской сессии.
Повтор инструкции о защите в нескольких ролях имеет смысл, пока общий файл
может быть недоступен в дочернем контексте. Пилот поддерживает выборочное
чтение как метод, а изменения этих правил требуют отдельного доказательства.
