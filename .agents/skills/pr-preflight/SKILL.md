---
name: pr-preflight
description: Проверяет объём изменений, локальные проверки и состояние review и CI перед публикацией или обновлением Draft PR Laterna VTT.
---

1. Сверь всё, что войдёт в PR, с критериями задачи. Проверь diff относительно merge base с актуальным master, staged и unstaged diff и новые файлы. Проверь `git diff --check` для этих изменений и исключи чужую работу, секреты и игровые данные.
2. Выбери и выполни профильные проверки по [руководству](../../../docs/DEVELOPMENT.md#все-проверки). Зафиксируй команду, итог и проверенный SHA или состояние рабочего дерева.
3. По [Git workflow](../../../AGENTS.md#git-workflow) проверь существующий PR и review. При изменении HEAD сравни diff с одобренным SHA. После локальных проверок публикуй разрешённый Draft или обновляй ту же ветку открытого PR.
4. Сверь Draft и его полный HEAD, затем проверь Fast CI для этого SHA по [порядку проверок](../../../docs/agent-workflow/CODEX_WORKFLOW.md#draft-pr-и-доказательства-проверок). Передай PR и SHA на независимое review. Любые дальнейшие действия зависят от условий задания и полного Git workflow.
