---
name: task-start
description: Уточняет объём новой задачи Laterna VTT перед правками, сверяет master, рабочую ветку и PR и фиксирует критерии готовности и стоп-условия.
---

1. Из [правил проекта](../../../AGENTS.md) и задания выпиши результат, критерии приёмки, ограничения и точку остановки. Используй [шаблон](../../../docs/agent-workflow/TASK_TEMPLATE.md), если задаче нужен отдельный документ.
2. От корня проверь `git status --short --branch`, полный `git rev-parse HEAD`, staged и unstaged diff. Сверь удалённый `master` и открытые PR. Для существующего PR проверь номер, состояние, целевую ветку и полный HEAD. Отметь недоступные внешние сведения и учитывай их при выборе действий.
3. Определи затронутые модули, прочитай их инструкции и разделы документов, на которые указывают правила проекта. Сверь спорное поведение с кодом и тестами на текущем SHA.
4. Зафиксируй основание ветки, критерии, профильные проверки и ограничения по данным, совместимости и публикации. Для небольшой однозначной правки достаточно записи в чате. Для изменений контрактов согласуй открытые решения до зависимой реализации. [Выбор плана](../../../docs/agent-workflow/CODEX_WORKFLOW.md#спецификация-и-план).
