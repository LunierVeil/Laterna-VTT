---
name: handoff-create
description: Сохраняет краткую локальную передачу контекста при паузе, смене сессии или приближении лимита Codex в Laterna VTT.
---

1. Сними фактический Git status, ветку и полный HEAD. Запиши PR и его HEAD, если они проверены. При незакоммиченном diff перечисли связанные пути, чтобы результат тестов не приписывался чистому HEAD.
2. Сохрани краткую запись по [формату handoff](../../../docs/agent-workflow/CODEX_WORKFLOW.md#запись-handoff) в `.agent-handoffs/<задача>.md` от корня. Подтверди, что путь игнорируется через `git check-ignore`; если файл уже отслеживается или путь выходит из каталога через симлинк, выбери безопасный локальный путь внутри каталога. Сохрани чужие записи.
3. Исключи секреты, пользовательские данные, большие логи и полный diff. Различай проверенные факты, запланированные действия и открытые вопросы. Сообщи относительный путь и ближайший незавершённый шаг.
