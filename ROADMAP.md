# Laterna VTT - дорожная карта

Что входит в каждую версию, кто тестирует и что считается готовностью.
Версия переходит дальше не когда сделаны фичи, а когда выполнены
**критерии выхода**.

Главное отличие этапов - не количество фич, а то, **чьи данные** на
сервере:

| этап | кто играет | данные |
|---|---|---|
| альфа | ты и друзья, один мастер | можно стирать базу |
| бета | 2-3 чужих мастера со своими группами | стирать нельзя, нужны миграции |
| 1.0 | кто угодно, кто скачал | обещание: обновление не ломает сохранения |

## Альфа 0.1 - "можно провести сессию"

**Цель:** отыграть с друзьями одну полную сессию от начала до конца
без света, но и без костылей.

### Что должно быть
- [x] Лист персонажа: ручная форма + импорт из Long Story Short
- [x] Бросок атаки и урона по клику из листа, кубы понимают `к`
- [x] Ресурсы со счётчиками, короткий и долгий отдых
- [x] Токен привязан к листу: хиты и КД на токене
- [x] Двери: открыть и закрыть, закрытая блокирует движение
- [x] Картинки на токенах вместо кружков
- [x] Трекер инициативы
- [x] Линейка расстояний
- [x] Скрытые броски мастера
- [x] Токены слоя ГМ не уходят игрокам (сейчас утечка)
- [x] Мобы и NPC: лист-шаблон у ГМ, на карте экземпляры со своими хитами
- [x] Интерфейс по первичному макету: колонка инструментов, вкладки, карточка токена
- [x] Запуск одной командой, фронт и API на одном порту
- [x] Туннель: игроки заходят по ссылке без проброса портов
      (в России зарубежные туннели режут - игрокам нужен VPN, см. README)

Найдено при проверке:
- [x] Лист: бонусы навыков и спасбросков считаются из характеристик и
      мастерства (свой бонус главнее)
- [x] Лист: история персонажа и черты характера текстом, импорт LSS кладёт
      их туда
- [x] Моб: характеристики и опасность
- [ ] Публичный доступ: основной путь - российский VPS с доменом и Caddy;
      туннель и VPN-сеть (Radmin VPN, ZeroTier) - запасные. Проверять надо
      на связке "провайдер - сервис": серверы российских туннелей (xTunnel,
      CloudPub) заранее не проверены

### Что тестируем
- Полную сессию 3-4 часа с 3-5 игроками
- Переподключение: закрыл вкладку, пропал интернет, перезапустил сервер
- Одновременные действия: двое двигают токены, мастер меняет сцену
- Импорт LSS на 3-5 разных персонажах, включая заклинателя
- Задержку через туннель: действие видно у всех меньше чем за секунду
- Записывать, что мастер делает руками снова и снова, - по этому решаем,
  какую автоматику делать

### Критерии выхода
- 2 сессии подряд без перезапуска сервера и без потери данных
- Ни одного случая "у меня не так, как у тебя" (рассинхрон)
- Игроки не спрашивают мастера, как сделать базовое действие

## Бета 0.5 - "делает то, ради чего задумано"

**Цель:** чужой мастер, который сейчас на Roll20 или Owlbear,
проводит в Laterna свою обычную игру и не хочет обратно.

### Что должно быть
- [ ] Редактор стен: стены, двери, окна, барьеры, удобная разметка
      по картинке
- [ ] Разметка стен и света по готовой картинке за минуты - главная задача
      редактора; рисование комнаты с нуля (комната одним действием, заливка
      пола, расстановка ассетов) - вторым шагом, с лимитом по времени
- [ ] Фигуры с галочкой "фигура создаёт стены"
- [ ] Импорт Universal VTT (.dd2vtt, .uvtt, .df2vtt) со стенами и светом
- [ ] Видимость токена: игрок видит только то, что видит его персонаж
- [ ] Источники света: факелы, фонари, тёмное зрение
- [ ] Туман войны с памятью разведанного
- [ ] Библиотека ассетов, загрузка своих паков, стартовый набор
- [ ] В библиотеке у ассета видна лицензия и происхождение (CC0, CC-BY,
      свой, сгенерировано)
- [ ] Цель атаки: выбрать чужой токен целью, бросок из листа пишет
      "атака -> Гоблин, 15 фт". Без автоматики: попал или нет и урон
      решает мастер (КД монстра игроку не виден, правил в ядре нет)
- [ ] Бестиарий: готовые мобы, из которых ГМ делает свою копию
      (шаблон и «Копия» уже есть с альфы)
- [ ] Макет интерфейса второго уровня (первичный - в альфе)
- [ ] Раздаточные материалы: ГМ показывает игрокам картинку или текст
      поверх стола
- [ ] Настройки кампании: переключатели видимости (КД и хиты монстров для
      игроков) и наборы автоматики ("без автоматики" по умолчанию,
      "помощь мастеру"); каждый переключатель выключен, пока мастер не
      включит
- [ ] Несколько кампаний у мастера (решить вопрос модели аккаунтов)
- [ ] **Миграции базы (alembic)** - у бета-мастеров настоящие данные
- [ ] Резервная копия кампании: выгрузить и загрузить
- [x] Ограничение попыток входа (сделано раньше, вместе с туннелем)
- [ ] Строки интерфейса вынесены в файлы перевода

### Что тестируем
- Подготовку сцены мастером: карта из Dungeondraft -> играбельная
  сцена со светом. Засечь время, сравнить с Roll20/Owlbear
- Производительность: 30 токенов, 15 источников света, 200 стен -
  без тормозов на среднем ноутбуке игрока
- Свет на краевых случаях: углы стен, открытые двери, окна, несколько
  источников
- Обновление версии на сервере с живыми данными
- Фидбек мастеров: что раздражает, чего не хватает, ушли бы обратно?

### Критерии выхода
- Хотя бы один чужой мастер провёл 3+ сессии и остался
- Обновление между версиями ни разу не потеряло данные
- Свет не пропускает обзор сквозь стены ни в одном найденном случае

## 1.0.0 - "можно отдавать незнакомым людям"

**Цель:** мастер находит проект на GitHub, ставит сам по инструкции
и играет. Без тебя рядом.

### Что должно быть
- [ ] Установка одной командой по инструкции, проверенной на чистой
      машине (Linux, Windows через Docker)
- [ ] Документация: для мастера (установка, подготовка сцены) и для
      игрока (как войти, как пользоваться листом)
- [ ] Английский интерфейс полностью
- [ ] HTTPS из коробки или чёткая инструкция
- [ ] Режиссёр событий - минимальная версия, можно выключить
- [ ] Все известные утечки и дыры закрыты, отдельное ревью безопасности
- [ ] Совместимость сохранений: 1.x открывает данные любой 1.y

### Что тестируем
- Установку человеком, который проект не видел, только по README
- Безопасность: попытки игрока увидеть скрытое, подменить чужое,
  перебрать пароль
- Долгую кампанию: месяц игры, десятки сцен, сотни сообщений
- Обновление с последней беты на 1.0 на реальных данных

### Критерии выхода
- Незнакомый человек поставил и провёл сессию без вопросов к тебе
- Ни одной открытой проблемы безопасности
- Бета-мастера перешли на 1.0 без потери данных

## После 1.0 - не обещаем

- Кадрирование картинки токена: игрок сам двигает и масштабирует её в
  круге (сейчас - обрезка по центру)
- Гексагональная сетка
- Модули листов под другие системы, кроме D&D 5e
- Голосовой чат
- Импорт карт из Azgaar Fantasy Map Generator
- Генерация таверн и NPC на таблицах Eigengrau
- Анимированные карты
- Мобильная версия для игроков
- Анимированные кубы поверх стола (результат бросает сервер, анимация
  только косметическая, выключается в настройках)
- Необязательные дополнения с ML, выключены по умолчанию: подсказка стен
  по картинке, вырезание фона токена, транскрипция сессии
- Музыка: свои файлы мастера и стартовый набор CC0/CC-BY отдельным пакетом
  с файлом CREDITS (не в репозитории); внешние сервисы - только встроенным
  плеером, без скачивания звука
- Журнал кампании (страницы, показ игрокам) - продолжение раздаточных
  материалов
- Простые макросы - сохранённые броски кнопкой; скрипты не обещаем
- Расширенная автоматика: проверка попадания по КД цели, расход ячеек
- Панель партии внизу и мини-карта разведанного
- Вопрос денег (пожертвования, платный хостинг) не решаем до 1.0

## Не делаем вообще

- Создатель персонажа с проверкой правил
- Парсинг dnd.su и других сайтов
- Встроенные чужие паки ассетов без лицензии на распространение

---

## Правило

Новая идея по ходу работы идёт в **"После 1.0"**, а не в текущий
этап. Перенести её выше можно только если без неё не выполнить
критерий выхода текущего этапа.
