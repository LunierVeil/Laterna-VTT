# Laterna VTT - дорожная карта

Что входит в каждую версию, кто тестирует и что считается готовностью. Версия переходит дальше не когда сделаны фичи, а когда выполнены **критерии выхода**.

Главное отличие этапов - не количество фич, а то, **чьи данные** на сервере:

|этап|кто играет|данные|тип игры, который подходит на этом этапе|
|---|---|---|---|
|альфа **0.1.0**|мои друзья и знакомые мастера|можно стирать базу|маленькие ваншоты|
|бета **0.5.0**|мои мастера + 1-3 знакомых мастера моих друзей|стирать нельзя, нужны миграции|ваншоты и небольшие кампании|
|бета удобства **0.8.0**|те же мастера, но с длинными кампаниями|у мастеров свои данные, обновление их не ломает|кампании с большим количеством сцен|
|**1.0**|кто угодно, кто скачал|обещание: обновление не ломает сохранения|любая|
|после релиза **1.x.x**|кто угодно, кто скачал|то же обещание|новые функции из раздела «После 1.0»|

- [x] Лист персонажа: ручная форма + импорт из Long Story Short
- [x] Бросок атаки и урона по клику из листа, кубы понимают `к`
- [x] Ресурсы со счётчиками, короткий и долгий отдых
- [x] Токен привязан к листу: хиты и КД на токене
- [x] Двери: открыть и закрыть, закрытая блокирует движение
- [x] Картинки на токенах вместо кружков
- [x] Трекер инициативы
- [x] Линейка расстояний
- [x] Скрытые броски мастера
- [x] Токены слоя ГМ не уходят игрокам (была утечка)
- [x] Мобы и NPC: лист-шаблон у ГМ, на карте экземпляры со своими хитами
- [x] Интерфейс по первичному макету: колонка инструментов, вкладки, карточка токена
- [x] Запуск одной командой, фронт и API на одном порту
- [x] Доступ для RU-сегмента: локальная сеть через Porthole или аналоги

Найдено при проверке:

- [x] Лист: история персонажа и черты характера текстом, импорт LSS кладёт их туда
- [x] Моб: характеристики и опасность
- [x] Пинг на карте: Alt+клик, кольцо с именем у всех
- [x] Ручной туман (заглушка): ГМ закрывает и открывает прямоугольники, под туманом игроку не уходят токены и стены. Не открывается от токенов, без памяти разведанного, карта скрыта только визуально

### Найдено на тесте у стороннего мастера (27.10.2026)

Первая отдача альфы наружу. Мастер не смог начать игру - значит критерий выхода «игроки не спрашивают мастера, как сделать базовое действие» не выполнен. Эти пункты остаются в альфе, а не переносятся дальше:

- [ ] **[токены]** Игрок ставит своего персонажа на карту перетаскиванием из списка, токен создаётся уже привязанным к листу. Нынешний путь (создать токен → настройки → лист) мастер не нашёл
- [ ] **[токены]** В списке привязки токена к листу игрок видит только свои листы. Сервер это уже проверяет (`_linked_character`: игроку - свой лист, ГМ - любой), проверить интерфейс
- [ ] **[лист]** Главная вкладка листа как первая страница бумажного листа: характеристики, под каждой её спасбросок и навыки; КД, инициатива, скорость, хиты, кости хитов, спасброски от смерти; таблица атак; бонус мастерства, вдохновение, пассивная внимательность. Отдельная вкладка «Навыки» убирается. Свой дизайн, без логотипа и рамок официального бланка
- [ ] **[токены]** Контекстное меню токена прямо на карте: слой, скрыть/показать, хиты, в инициативу. Без захода в боковую панель
- [ ] **[сцена]** Привязка к сетке отключается в настройках сцены, свободное размещение и шаг привязки
- [ ] **[лист]** Временные хиты при уроне. Заодно решить: урон вводится руками (тогда временные хиты вычитает человек) или сервер применяет одно правило - это первый кусок правил в ядре, записать в ARCHITECTURE.md как исключение
- [ ] **[сцена]** Поле родителя (папки) в схеме сцен и персонажей, без интерфейса. Интерфейс в 0.8. По тому же правилу, что и флаги стен: добавить поле сейчас дешевле, чем переделывать схему потом

- [ ] **[сеть]** Игрок вне России и с телефона: Porthole на телефоне нет. Проверить туннель Cloudflare и ZeroTier; если не работают - российский VPS с Caddy и обратным туннелем

Отмечено мастером как сильная сторона, ломать нельзя: настройка токена прямо на карте - удобнее, чем в Roll20.

Баги, найденные на тестах, записываются в BUGS.md с приоритетом P0-P3 и областью. Открытый P0 не даёт выйти из альфы.

### Что тестируем

- Полную сессию 3-4 часа с 3-5 игроками
- Переподключение: закрыл вкладку, пропал интернет, перезапустил сервер
- Одновременные действия: двое двигают токены, мастер меняет сцену
- Импорт LSS на 3-5 разных персонажах, включая заклинателя
- Задержку в сети, через которую играем: действие видно у всех меньше чем за секунду
- Записывать, что мастер делает руками снова и снова, - по этому решаем, какую автоматику делать
- Посадить нового мастера за стол и не подсказывать. Всё, что он не нашёл за 10 минут, - дефект интерфейса, а не его невнимательность

### Критерии выхода

- 2 сессии подряд без перезапуска сервера и без потери данных
- Ни одного случая "у меня не так, как у тебя" (рассинхрон)
- Игроки не спрашивают мастера, как сделать базовое действие

## Бета 0.5.0 - "делает то, ради чего задумано"

**Цель:** чужой мастер, который сейчас на Roll20 или Owlbear, проводит в Laterna свою обычную игру и не хочет обратно.

### Что должно быть

**Сцена и свет**

- [ ] Редактор стен: стены, двери, окна, барьеры, удобная разметка по картинке
- [ ] Разметка стен и света по готовой картинке за минуты - главная задача редактора. Рисование комнаты с нуля (комната одним действием, заливка пола, расстановка ассетов) - вторым шагом, с лимитом по времени
- [ ] Фигуры с галочкой «фигура создаёт стены»
- [ ] Импорт Universal VTT (.dd2vtt, .uvtt, .df2vtt) со стенами и светом
- [ ] Видимость токена: игрок видит только то, что видит его персонаж
- [ ] Источники света: факелы, фонари, тёмное зрение
- [ ] Туман войны с памятью разведанного (динамический, от зрения токенов; ручной туман-заглушка есть с альфы)

**Токены**

- [ ] Выделение нескольких токенов и выбор нескольких целей
- [ ] Цель атаки: выбрать чужой токен целью, бросок из листа пишет «атака → Гоблин, 15 фт». Без автоматики: попал или нет и урон решает мастер (КД монстра игроку не виден, правил в ядре нет)

**Лист**

- [ ] Лист моба полностью: заклинания, бонусные действия, реакции, легендарные и логовищные действия. Сейчас этих разделов нет, с ними нельзя вести нормального босса
- [ ] Библиотека заклинаний: добавить в книгу из своего набора кампании (тексты книг в проект не кладём - только свои и свободные)
- [ ] Бестиарий: готовые мобы, из которых ГМ делает свою копию (шаблон и «Копия» уже есть с альфы)

**Кампания**

- [ ] Библиотека ассетов, загрузка своих паков, стартовый набор
- [ ] В библиотеке у ассета видна лицензия и происхождение (CC0, CC-BY, свой, сгенерировано)
- [ ] Раздаточные материалы: ГМ показывает игрокам картинку или текст поверх стола
- [ ] Настройки кампании: переключатели видимости (КД и хиты монстров для игроков) и наборы автоматики («без автоматики» по умолчанию, «помощь мастеру»); каждый переключатель выключен, пока мастер его не включит
- [ ] Несколько кампаний у мастера (решить вопрос модели аккаунтов)

**Интерфейс**

- [ ] Макет интерфейса второго уровня (первичный - в альфе)
- [ ] Строки интерфейса вынесены в файлы перевода

**Данные**

- [ ] **Миграции базы (alembic)** - у бета-мастеров настоящие данные
- [ ] Резервная копия кампании: выгрузить и загрузить
- [x] Ограничение попыток входа (сделано раньше)

### Что тестируем

- Подготовку сцены мастером: карта из Dungeondraft → играбельная сцена со светом. Засечь время, сравнить с Roll20/Owlbear
- Производительность: 30 токенов, 15 источников света, 200 стен - без тормозов на среднем ноутбуке игрока
- Свет на краевых случаях: углы стен, открытые двери, окна, несколько источников
- Бой на 8+ мобов с легендарными действиями: хватает ли листа моба
- Обновление версии на сервере с живыми данными
- Фидбек мастеров: что раздражает, чего не хватает, ушли бы обратно?

### Критерии выхода

- Хотя бы один чужой мастер провёл 3+ сессии и остался
- Обновление между версиями ни разу не потеряло данные
- Свет не пропускает обзор сквозь стены ни в одном найденном случае

## Бета удобства 0.8.0 - "кампания, а не ваншот"

**Цель:** на столе живёт кампания на десятки сцен и персонажей, и мастер не держит рядом отдельный файл, чтобы не потеряться.

Новых больших систем здесь нет. Это этап про порядок и руки: часть пунктов переехала сюда из «После 1.0», часть - прямой отклик на «пока твой стол подходит для небольших ваншотов».

### Что должно быть

**Порядок в материалах**

- [ ] **[сцена]** Папки для сцен, персонажей и ассетов: вложенность, перетаскивание, поиск по кампании. Поле родителя лежит в схеме с альфы
- [ ] **[сцена]** Перенос сцен и персонажей между кампаниями

**Руки мастера**

- [ ] **[токены]** Групповые операции: переместить, скрыть, показать, удалить пачкой. Выделение нескольких есть с беты
- [ ] **[токены]** Кадрирование картинки токена: игрок сам двигает и масштабирует её в круге _(переехало из «После 1.0»)_
- [ ] **[лист]** Простые макросы - сохранённые броски кнопкой; скрипты не обещаем _(переехало из «После 1.0»)_
- [ ] **[интерфейс]** Панель партии внизу и мини-карта разведанного _(переехало из «После 1.0»)_
- [ ] **[интерфейс]** Журнал кампании: страницы, показ игрокам - продолжение раздаточных материалов _(переехало из «После 1.0»)_

**Интерфейс**

- [ ] **[интерфейс]** Кнопка «Пинг» вместо Alt+ЛКМ. Это не только про телефон: на маке сочетание конфликтует с системными жестами
- [ ] **[интерфейс]** Чат и левая панель инструментов сворачиваются - на маленьком экране они съедают стол
- [ ] **[интерфейс]** Мобильная версия для игроков: лист с вкладками, блоки без прокрутки вбок, открытие почти на весь экран _(переехало из «После 1.0»)_
- [ ] **[лист]** Выбор раскладки листа: «Laterna» (компактная с вкладками), «классика 2014», «классика 2024». Данные у всех одни, меняется только вид. Выбор у каждого игрока свой, не у кампании. Поля 2024 (вид вместо расы, размер, героическое вдохновение, тренировка доспехов) - необязательные поля общей схемы. Оформление своё, без бланков WotC
- [ ] **[чат]** Анимированные кубы поверх стола - по желанию, не блокирует выход. Результат бросает сервер, анимация показывает уже известное число. Скрытые броски мастера игрокам не анимируются. Выключается в настройках, на слабых устройствах выключена по умолчанию _(переехало из «После 1.0»)_
- [ ] **[интерфейс]** Ревизия интерфейса по накопленному фидбеку бета-мастеров: что они делают чаще всего, то в один клик

### Что тестируем

- Кампанию на 20+ сцен и 30+ персонажей: сколько времени занимает найти нужное
- Подготовку мастера к сессии от открытия стола до готовой сцены
- Игрока с телефона на полной сессии
- Лист в классической раскладке у мастера, который привык к бумажному листу: находит всё без подсказки
- Обновление 0.5 → 0.8 на живых данных бета-мастеров

### Критерии выхода

- Мастер с большой кампанией находит нужную сцену или персонажа быстрее чем за 10 секунд, без поиска глазами по общему списку
- Ни один бета-мастер не ведёт параллельно внешний файл или таблицу, чтобы не запутаться в своих материалах
- Игрок провёл сессию с телефона и не просил ноутбук
- Переход с 0.5 на живых данных прошёл без потерь

### Что должно быть

- [ ] Документация: для мастера (установка, подготовка сцены) и для игрока (как войти, как пользоваться листом)
- [ ] Английский интерфейс полностью
- [ ] HTTPS из коробки или чёткая инструкция
- [ ] Режиссёр событий - минимальная версия, можно выключить
- [ ] Все известные утечки и дыры закрыты, отдельное ревью безопасности
- [ ] Совместимость сохранений: 1.x открывает данные любой 1.y

### Что тестируем

- Установку человеком, который проект не видел, только по README
- Безопасность: попытки игрока увидеть скрытое, подменить чужое, перебрать пароль
- Долгую кампанию: месяц игры, десятки сцен, сотни сообщений
- Обновление с последней беты на 1.0 на реальных данных

### Критерии выхода

- Незнакомый человек поставил и провёл сессию без вопросов ко мне
- Ни одной открытой проблемы безопасности
- Бета-мастера перешли на 1.0 без потери данных

## После 1.0 - не обещаем

- Гексагональная сетка
- Модули листов под другие системы, кроме D&D 5e
- Голосовой чат
- Импорт карт из Azgaar Fantasy Map Generator
- Генерация таверн и NPC на таблицах Eigengrau
- Анимированные карты
- Необязательные дополнения с ML, выключены по умолчанию: подсказка стен по картинке, вырезание фона токена, транскрипция сессии
- Музыка: свои файлы мастера и стартовый набор CC0/CC-BY отдельным пакетом с файлом CREDITS (не в репозитории); внешние сервисы - только встроенным плеером, без скачивания звука
- Расширенная автоматика: проверка попадания по КД цели, расход ячеек
- Вопрос денег (пожертвования, платный хостинг) не решаем до 1.0

## Не делаем вообще

- Создатель персонажа с проверкой правил
- Парсинг dnd.su и других сайтов
- Встроенные чужие паки ассетов без лицензии на распространение

## Правило

Новая идея по ходу работы идёт в **«После 1.0»**, а не в текущий этап. Перенести её выше можно, только если без неё не выполнить критерий выхода текущего этапа.

Фидбек мастера - это тоже новая идея, и правило на него распространяется. Исключение одно: если мастер не смог сделать на столе базовое действие, это не идея, а невыполненный критерий выхода текущего этапа, и чинится в нём.

## Исправления из BUGS (01.11.2026)

Реализованы исправления 12 записанных ошибок: транспорт и повторные снимки, размещение персонажей кнопкой и перетаскиванием, временные хиты, портреты и удаление привязок, расстояние и свободное перемещение, мобильный лист, пинг и сворачивание панелей.
